# Emotion Tracking and Happiness Optimization System

## Idea

A background app running on a smartphone that tracks the user’s emotions and combines this information with what they see on their screen.

Using the front-facing camera, the app detects facial expressions and records the corresponding emotions associated with the content displayed on the screen. This creates a user-specific dataset.

The collected data can then be used to improve the user experience in other apps.

## Implementation

### Front-Facing Camera for Emotion Detection

* Front-facing camera feed
* Emotion recognition based on facial expressions

### Screen Detection and Analysis
